# VNC 与 Telnet 资产

VNC 和 Telnet 都可以通过浏览器资产工作区接入，但用途和安全特性完全不同。

## VNC 资产

VNC 用于访问提供 VNC 服务的图形桌面。

### 添加与配置

1. 在「资产管理 > 资产」中新建资产。
2. 协议选择 `VNC`，默认端口为 `5900`。
3. 填写目标地址和 VNC 密码，或者选择密码凭证。
4. 目标位于内网时选择网关链。
5. 按需配置显示设置和 WOL。
6. 保存、测试并完成资源授权。

VNC 高级设置主要包括分辨率、色彩深度、缩放方式和 Wake-on-LAN。VNC 不提供 SSH 文件系统；复制粘贴能力取决于服务端兼容性和访问策略。

### 安全建议

- 确认 VNC 服务的认证和加密能力。
- 不要直接将 VNC 端口暴露到公网。
- 优先通过安全网关接入内网 VNC 服务。
- 严格限制共享账号的授权范围。

## Telnet 资产

Telnet 主要用于无法提供 SSH 的传统网络设备和遗留系统。

### 添加与配置

1. 新建资产并选择 `Telnet`，默认端口为 `23`。
2. 填写目标地址和端口。
3. Telnet 登录通常在终端建立后交互完成，因此资产表单不提供 SSH/RDP 那样的账户类型区域。
4. 按需配置网关链和 WOL。
5. 保存、测试并授权用户。

### 安全限制

Telnet 不加密协议内容，账号、密码和命令可能以明文在目标网络中传输。只应在隔离且可信的网络内使用；目标支持 SSH 时应迁移到 SSH。

## 文件管理

VNC 和 Telnet 会话不提供 Next Terminal 文件管理入口。如需传输文件，请根据目标系统改用 SSH/SFTP、RDP 网络驱动器或其他受控方式。

## 排障

- 检查 Next Terminal 或网关到目标端口的连通性。
- VNC 黑屏或协议错误请参阅 [RDP/VNC 错误码](/zh/usage/error-codes)。
- Telnet 建连后没有登录提示时，检查设备是否要求先按 Enter、使用特殊终端类型或经过串口服务器。
